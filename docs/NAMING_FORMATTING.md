# NPS V1 Naming and Formatting

## Standard labels

```text
Verdichter aktiv
Zusatzheizung aktiv
Enteisung aktiv
Zyklus aktiv

Warmwasser oben (BT7)
Warmwasserbereitung (BT6)

Technischer Anlagenzustand
NPS Health-Zustand
```

## Number formatting

```text
COP                  1 decimal place
Temperature          1 decimal place
Energy               1 decimal place
Power in kW          1 decimal place
Power in W           integer
Shares                integer %
Runtime               minutes
Date/time             DD.MM.YYYY, HH:mm
```

Tables may use `DD.MM.YYYY HH:mm` when the value is centrally generated in that form.

## Overview principle

The main page answers:

> What is the system doing right now?

Detail pages answer:

> Why is it doing that, and how has it developed over time?
